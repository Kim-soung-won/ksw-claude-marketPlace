# component-documentation

업무 절차의 원본은 [component-skill-manager 절차](../../resources/component-skill-manager/procedure.md)다.

component-skill-manager 에이전트가 등록되어 있고 위임 도구를 쓸 수 있으면 컴포넌트명·소스 경로·
목적·저장할 프로젝트를 전달해 위임하고, 반환된 결과 리포트를 그대로 전달한다.
에이전트를 쓸 수 없으면 위 절차 문서를 읽고 현재 에이전트가 같은 절차를 직접 수행한다.
