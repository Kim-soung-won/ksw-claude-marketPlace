# Codex Docs Plugin

Codex 설정·스킬·커스텀 에이전트·플러그인·훅·MCP의 생성·수정·진단을 돕는다.
`codex-docs` 스킬 1개와 공식 문서 진입점, 작성·검증, 진단·이식 참조 문서로 구성한다.
규격 전문을 복사해 고정하지 않고 작업 시점의 공식 문서와 로컬 환경을 함께 확인한다.

## 설치와 사용

Codex에서는 [저장소 설치 안내](../../docs/codex.md)에 따라 카탈로그를 등록한 뒤
`Codex Docs`를 설치한다. 에이전트 등록 도구는 필요하지 않다.
Claude Code에서도 Codex 설정을 관리할 수 있도록 같은 스킬을 배포한다.

```text
/plugin install codex-docs-plugin@ksw-plugins
```

사용 예:
- `Codex 스킬 만들어줘. 이 저장소의 테스트 리뷰 규칙을 재사용하고 싶어.`
- `Codex 에이전트 설정을 공식 규격에 맞게 검토해줘.`
- `Codex에서 이 플러그인이 안 보이는 원인을 찾아줘.`
- `이 Claude 플러그인을 Codex로 이식해줘.`

공식 문서 조회에는 호스트가 제공하는 웹·문서 검색 도구가 필요하다. 별도 MCP 서버를
설치하지 않는다. 조회할 수 없는 환경에서는 로컬 확인과 최신 규격 미확인을 구분한다.
정적 검증은 실제 클라이언트에서의 자동 스킬 선택·작업 성공을 보장하지 않는다.
