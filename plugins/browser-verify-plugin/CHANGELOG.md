# 변경 이력

## [0.1.0] — 2026-11-17

- Claude Code·Codex 공용 browser-verify 스킬과 양쪽 카탈로그를 등록했다.
- 정해진 점검 순서를 두지 않고, 지켜야 할 것 다섯 가지와 판단 지침(위험 가설에서 계획 세우기, 계획 바꾸기, 막혔을 때)을 중심으로 구성했다.
- 임시 Chrome 실행·접속·빌드 로드 확인 방법과 측정 방법 모음(키보드·포커스·폼·폭별 넘침·layout shift) 문서를 추가했다.
- 스크린샷을 찍는 기준과 여는 기준, 서버 데이터를 바꾸지 않는 안전 장치, 근거를 구분하는 보고 형식을 추가했다.
- 부품으로 쓰는 스크립트(Chrome 실행, 준비, 공통 측정 모듈, 화면 조사, 다이얼로그 점검 예시)를 추가했다.
- 점검마다 배운 것을 쌓는 개선 기록을 추가했다.
- 개발자에게 결정을 요청할 때 참고할 출처(웹 표준 주제는 `modern-web-guidance` 가이드)를 함께 언급하는 지침을 추가했다. 가이드를 판정 기준으로 강제하지는 않는다.
