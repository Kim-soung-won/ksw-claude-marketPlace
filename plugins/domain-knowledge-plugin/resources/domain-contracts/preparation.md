# 계약 준비 절차

## 1. 기능과 근거 조사

기존 지식·계약·테스트·사용자 변경을 먼저 확인하고 기능별로 신규/기존/변경을 나눈다.
문서·Swagger/OpenAPI·업무 시나리오의 출처, 버전 또는 수집 시점, 위치/operationId를
기록한다. 제공된 자료만으로 충분하면 외부 수집을 요구하지 않는다. 접근하지 못한 자료를
읽었다고 가정하지 않고 필요한 계약만 미확정으로 남긴다.

- 전송 계약: method/path, 파라미터 위치, required/optional/nullable, enum, 중첩·배열,
  성공/에러 응답, 페이지네이션. 예시 JSON만으로 필수 여부·모든 enum 값을 확정하지 않는다.
- 도메인 의미: 식별자, 금액·시간 단위, DTO→Entity 변환, 상태와 불변식.
  상태·플래그·코드 필드는 값별로 현실·시스템에서 가리키는 상태를 `_domain` 필드 의미로 기록한다.
- 업무 시나리오: 사용자의 목적, 성공·실패·복구. API만으로 화면 권한·버튼 노출·
  상태 전이·재시도 정책을 만들어내지 않는다.

충돌 시 원본별 내용을 함께 기록하고 해당 계약만 보류한다. 구현을 문서보다, 문서를
실측보다 무조건 우선하지 않는다. 코드에서만 관찰한 내용은 미승인 현재 동작으로 기록한다.

## 2. 지식과 코드의 권위

지식 관리자의 기존 trio 구조를 재사용한다. 문서는 의미·제약·출처와 코드 위치를,
실행 스키마는 검증 계약을 소유한다. 코드 계약이 있으면 문서에 타입을 재정의하지 않고
파일과 export를 참조한다. 기존 스킬 이름·프로젝트 저장 위치는 유지한다.
공통 인증·에러·클라이언트의 기존 계약을 참조하고 도메인 안에 복제하지 않는다.

## 3. 논리 계층 준비

읽은 FSD 원본과 프로젝트 관례로 경로·public API를 결정한다. 새 계약은 `shared/api`,
도메인 변환·불변식·데이터 접근은 `entities` 범위로 제한한다. 그룹·도메인 이름은
기존 메뉴·경로 설정에서 확인하며 확인할 수 없으면 사용자 제공 이름을 사용하거나 묻는다.

- 기존 스키마·타입·서비스를 먼저 재사용한다. 이미 완성된 도메인을 재생성하지 않는다.
- 요청/응답 DTO 스키마와 파생 타입, service의 직렬화·에러 계약을 맞춘다.
- Entity 스키마와 DTO 변환에서 서버와 화면 표현의 차이를 명시한다. 근거 없이
  기본값·날짜 변환·enum fallback을 추가하지 않는다.
- 필요한 query/mutation·필터만 준비한다. 화면 정책이 미정이면 그 부분은 남겨 둔다.
- 공용 인프라를 임의로 바꾸지 않는다. 기존 프로젝트가 다른 구조이면 현 위치에서
  계약을 대조하고 별도 구조 이관을 하지 않는다.
- 기존 계약의 동작 변경·호환성 파괴가 필요하면 관련 명세 테스트와 diff를 준비해
  개발자 검토로 넘긴다. 테스트 확보 요청을 기존 기능 수정 승인으로 해석하지 않는다.

타입 검사와 계약·변환·불변식 단위 테스트를 실행한다. 유효·무효 입력, 누락과 null,
빈 배열 등 실제 계약의 경계를 포함한다. 새로 구현한 논리 계층은 통과해야 준비 완료다.
기존 명세 불일치는 테스트로 드러내고 미해결 상태로 전달한다. 논리 계층까지 TDD인
요청은 프론트엔드 생명주기 원본의 spec-first 절차를 먼저 적용한다.

## 4. 전달 형식

```markdown
## 도메인 계약 준비 결과
- 대상 기능과 진입 상태:
- 근거: {출처·버전·위치·확인 상태}
- 도메인 지식: {trio 파일 링크}
- 논리 계약: {재사용/신규/수정 제안 파일과 public export}
- 검증: {명령·실행 결과·미실행 이유}
- 미확정/충돌: {영향받는 기능과 다음 판단}
- 기존 동작 관찰: {명세로 승인되지 않은 사항}
- UI 테스트에 전달할 시나리오·계약 참조: {`_scenario` 화면 분기 근거와 `_domain` 필드 의미 항목 포함}
- 준비 완료/부분 준비/보류와 다음 작업:
```

실행하지 않은 검사를 통과로 채우지 않는다. 하네스가 있다면 그 작업 기록에 연결하고,
없으면 위 결과로 반환한다. 이 단계에서 UI 명세서를 따로 작성하지 않는다.
