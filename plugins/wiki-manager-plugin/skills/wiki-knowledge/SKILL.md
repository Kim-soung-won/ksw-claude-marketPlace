# wiki-knowledge

업무 절차의 원본은 [wiki-manager 절차](../../resources/wiki-manager/procedure.md)다.

wiki-manager 에이전트가 등록되어 있고 위임 도구를 쓸 수 있으면 노트로 남길 실질 내용(대화에서
추출한 것)이나 보강 대상 노트·범위, 대상 vault를 위임 프롬프트에 담아 위임하고, 반환된 노트
경로·위키링크 목록을 그대로 전달한다. 에이전트를 쓸 수 없으면 위 절차 문서를 읽고 현재
에이전트가 같은 절차를 직접 수행한다.
