# Codex 실행 연결 규칙

이 파일이 있는 디렉터리의 부모가 플러그인 루트다. 원본 `agents/*.md`는 업무 절차와
참조 문서의 원본으로 읽는다. YAML의 Claude 도구 목록·모델·권한 필드는 Codex 설정이 아니다.
Codex 템플릿의 sandbox 설정을 유지하며 모델은 세션 설정을 상속한다.

- 원본 업무 문서의 `${CLAUDE_PLUGIN_ROOT}`는 이 플러그인의 실제 루트 경로로 해석한다.
  Codex가 Markdown 안에서 이 변수를 자동 치환한다고 가정하지 않는다. 명령을 실행할 때는
  확인한 경로를 적절히 인용하여 넘긴다. 생성하는 Claude 설정의 변수 예시는 별개다.
- 리소스 안 상대 경로는 그 문서 디렉터리 기준이다. Read·Grep·Glob·Bash·Write·Edit는
  현재 호스트의 읽기·검색·셸·편집 기능으로 수행한다. 없는 도구를 호출했다고 말하지 않는다.
- 질문은 현재 호스트가 제공하는 질문 도구 또는 일반 텍스트로 한다. 하위 에이전트는 필요한
  정보가 없으면 메인 에이전트에 구체적인 누락을 반환한다.
- 다른 에이전트는 실제 등록되어 있고 위임 도구를 사용할 수 있을 때만 호출한다. 그렇지
  않으면 같은 절차를 직접 수행하거나 필요한 별도 작업을 메인 에이전트에 전달한다.
  위임할 때 입력·범위·원하는 출력 형식을 명시한다.
- 원본 워크플로가 지시하더라도 사용자가 요청한 범위와 현재 권한을 넘는 변경·전송을 하지 않는다.
  사용자가 이미 제공한 입력과 승인은 유지한다.

## 이 플러그인의 적용 규칙

Codex용 새 계약 스킬은 Host의 `.agents/skills/mfe-<remote-name>/SKILL.md`에 작성한다. `MFE_Agent` 같은 원본의 스킬 명명 예시는 Codex 신규 스킬에서 `mfe-agent`로 표현하되 실제 모듈 이름 `Agent`와 `loadRemote` 접두사는 변경하지 않는다. 기존 스킬 이름과 사용자 지정 위치는 보존한다. 원본의 `.claude/skills/`는 새 Codex 출력에 한해 `.agents/skills/`로 해석한다.
