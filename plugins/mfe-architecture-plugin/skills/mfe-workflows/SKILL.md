# mfe-workflows

아래에서 요청에 맞는 업무 하나를 선택한다. 각 업무 절차의 원본은 표의 procedure.md다.

| 업무 | 원본 절차 |
|---|---|
| 팀 Module Federation 설정을 생성하거나 Host·Remote 구성을 검토한다. | [mfe-config-architect 절차](../../resources/mfe-config-architect/procedure.md) |
| Remote의 실제 exposes와 props를 조사해 소비 프로젝트의 계약 스킬을 기록한다. | [remote-contract-manager 절차](../../resources/remote-contract-manager/procedure.md) |

해당 이름의 에이전트가 등록되어 있고 위임 도구를 쓸 수 있으면 입력·범위·출력 형식을
전달해 위임하고, 반환된 결과를 그대로 전달한다. 에이전트를 쓸 수 없으면 선택한 절차
문서를 읽고 현재 에이전트가 같은 절차를 직접 수행한다. 결과는 절차가 지정한 형식을 따른다.
